About the Project

This project focuses on the front-end design of a modern trading platform homepage. The goal was to create a professional, visually engaging landing page that communicates the platform’s features while providing a smooth and responsive experience across different screen sizes.

The page combines a dark fintech-inspired visual style with clean typography, market-focused visuals, responsive layouts, feature sections, portfolio information, and clear calls to action.

Built with HTML, CSS, and Bootstrap, this project demonstrates my approach to creating structured, responsive, and polished web interfaces from the front end.
